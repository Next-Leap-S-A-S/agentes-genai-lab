Un agente no es un chat. Es un encargo con ingredientes.

Rol, Contexto e Instruccion ya los conoces del taller de prompts. Hoy los vas a usar para armar tu primer agente en Allianz GenAI-Lab, de principio a fin.

/concepto

¿Que es un agente de IA?

Es un asistente armado a la medida: tiene su propio rol, su propio conocimiento y sus propias herramientas.

/rolR

Quien es tu agente

El system prompt y el modelo definen su rol, su tono y su forma de pensar.

Eres un asistente que redacta certificados laborales, en tono formal y en espanol.

Si falta: respuestas genericas, sin personalidad ni criterio propio.

/contextoC

Que sabe de tu caso

La Knowledge Base y los Agent Files son lo que el agente puede consultar antes de responder.

Plantillas de certificados, politicas internas, tarifario vigente.

Si falta: el agente inventa datos que deberia estar consultando.

/instruccionI

Que debe entregar

Las herramientas (Tools) son los medios con los que produce el resultado esperado.

Generar el certificado, buscar en la web, armar una presentacion.

Si falta: el agente sabe que hacer, pero no tiene con que hacerlo.

/por-que-un-agente

Del prompt que repites al agente que armas una vez

Un prompt bien escrito resuelve una tarea. La resuelve una vez, con los datos que tenias a mano ese dia. La siguiente vez que necesitas lo mismo, lo vuelves a escribir. Cambias el nombre, la fecha, el numero de poliza.

Diez personas redactan el mismo tipo de certificado, cada una con su propia version del prompt, cada una llegando a un resultado distinto. El prompt funciona. Lo que vive solo en tu cabeza es la version buena.

Un agente guarda esa receta una sola vez. El rol, el contexto y la instruccion quedan fijos: en el system prompt, conectados a los documentos correctos, con las herramientas que hacen falta. Se escribe una vez. Despues lo usa todo el equipo, incluida la persona que nunca lo escribio.

Armar un agente toma tiempo. Para una tarea que haces una sola vez, un prompt suelto sigue siendo la herramienta correcta. Lo que importa es si tu caso lo necesita.

/aplicacion

Los pasos, en Allianz GenAI-Lab

Con la receta lista, esto es lo que vas a hacer dentro de la plataforma.

1🌱

Crear el agente

Entra a Configure AI Agents. Ahi esta el boton + New AI Agent. Cada agente que crees queda en esa lista, listo para editarlo o duplicarlo despues.

2📝

Nombre, descripcion y system prompt

El nombre y la descripcion son lo primero que ve quien use tu agente. La descripcion funciona como mensaje de bienvenida, con un limite de 256 caracteres.

El system prompt va debajo. Ahi pegas la receta que ya escribiste: rol, tono, formato y limites.

3🧲

Activar las herramientas

Cada herramienta es un interruptor independiente. Enciende las que tu caso de uso realmente necesita.

🔍

Web Search

Web Search conecta al agente con Google. El agente decide cuando lanzar una busqueda, segun lo que necesite para responder. Los resultados entran al contexto de la conversacion como texto plano, no como enlaces que el usuario pueda verificar por su cuenta.

La activacion es por sesion, no por agente. Cada usuario prende o apaga la herramienta desde el chat. La decision no se guarda para la proxima conversacion.

  • Sirve para preguntas con respuesta publica y cambiante: tasas, normativas vigentes, noticias del sector asegurador.
  • Polizas, siniestros y datos internos de Allianz viven en otro lugar. Google no llega ahi.
  • Trae lo primero que encuentra, tal cual aparece, sin filtrar la fuente.

Ejemplo: un asesor comercial pregunta si cambio el tope de la UVT para el ano en curso, antes de calcular una prima. El agente busca en la web y encuentra la cifra publicada por la DIAN.

🧮

Code Interpreter

El agente deja de describir los datos. Empieza a trabajar con ellos.

Con una base de siniestros, ejecuta el codigo, calcula la cifra exacta y la muestra.

  • Analiza bases de polizas, siniestros y reclamaciones
  • Hace calculos actuariales y financieros
  • Genera graficos y tableros de resultados
  • Automatiza tareas repetitivas sobre archivos
  • Resuelve tareas a la medida que no caben en un flujo estandar

Ejemplo: un analista de siniestros de autos sube el archivo del mes y pide el promedio de indemnizacion por ciudad, con un grafico de barras listo para el comite.

🎨

Image Generation

El agente genera imagenes desde una descripcion de texto y tambien las edita despues, sin salir del chat. La activacion es por sesion, igual que Web Search: se prende o se apaga con el mismo interruptor.

Sirve para piezas de apoyo rapido: un boceto para revisar antes de pasarlo a diseno grafico ahorra una vuelta completa de correos.

  • Genera una imagen nueva a partir de una descripcion escrita.
  • Edita una imagen ya generada dentro de la misma conversacion.
  • El interruptor queda en tus manos: se enciende cuando de verdad la necesitas.

Ejemplo: comunicaciones internas le pide al agente un banner para el correo de renovacion de polizas de auto, y despues le pide cambiar el color de fondo para la campana del mes.

📊

Build PowerPoint

Genera la presentacion completa en PowerPoint a partir del contenido que le entregues. Arma las diapositivas y ubica las imagenes en su lugar. Ademas mapea cada nombre de imagen a su file ID, y ese mapeo es el que arma el link de descarga del archivo final.

Antes de generar el archivo hay que elegir la plantilla correcta. Cambiarla despues implica rehacer el proceso completo.

  • white_template
  • blue_template
  • azse_white_template
  • azse_blue_template

Ejemplo: un analista prepara el informe trimestral de siniestros para el comite de riesgo. Carga las cifras y los graficos, elige blue_template y recibe el PowerPoint listo con su link de descarga.

📁

SharePoint MCP

Es un toolkit MCP (Model Context Protocol) que conecta al agente directamente con los sitios de SharePoint de Allianz, pensado para ese sistema interno especifico.

Web Search mira hacia afuera, a la web publica. SharePoint MCP mira hacia adentro, a los documentos y sitios que ya existen en la intranet.

  • El agente navega la estructura de sitios de SharePoint.
  • Trae el contenido encontrado sin que el usuario salga del chat.

Ejemplo: un analista de siniestros pide el procedimiento vigente para reclamos de auto por perdida total. El agente lo trae directo del sitio de SharePoint del area, sin buscarlo carpeta por carpeta.

📚

Confluence MCP

Conecta el agente con Confluence Master Platform (CMP), la wiki interna de Allianz. Consulta paginas existentes y tambien puede dejar contenido nuevo, sin que alguien tenga que copiar y pegar en el medio.

La respuesta que entrega depende de que tan actualizada este la pagina en CMP.

  • Busca contenido en la wiki por palabras clave o tema
  • Lee el contenido completo de una pagina especifica
  • Crea paginas nuevas dentro de CMP
  • Actualiza paginas ya existentes

Ejemplo: un agente de soporte interno busca en CMP el procedimiento vigente para reportar un siniestro de auto, lo lee y responde al asesor con el paso exacto que le faltaba.

🗂️

Jira MCP

Este toolkit conecta al agente con Jira Master Platform (JMP), el sistema donde Allianz Colombia gestiona sus proyectos. El agente lee y escribe directamente sobre los tickets reales. Nadie tiene que copiar datos a mano entre plataformas.

Cubre cinco frentes de trabajo dentro de JMP.

  • Busqueda y exploracion de proyectos e issues existentes
  • Sprints y tableros agiles, con su estado y avance
  • Creacion y actualizacion de issues
  • Relaciones entre tickets, como bloqueos o dependencias
  • Administracion de proyectos dentro de JMP

Ejemplo: un analista de siniestros pide el estado del sprint activo del equipo de reclamaciones. El agente entra a JMP, cruza las relaciones entre tickets y devuelve los issues bloqueados por falta de informacion del cliente.

📖

Read File Toolkit

Es la capacidad del agente para leer un archivo de verdad durante la conversacion. Otra cosa es guardarlo en Agent Files o en la Knowledge Base. Esta herramienta es la que hace que el agente lo abra y entienda lo que hay adentro.

  • Revisa la estructura del archivo antes de leerlo completo
  • Lee el contenido entero cuando hace falta
  • Salta a paginas especificas sin cargar todo el documento
  • Busca un termino dentro del contenido
  • Ve imagenes que le compartas
  • Convierte una pagina de PDF en imagen para analizarla

Ejemplo: un analista de siniestros sube el PDF de un dictamen medico de treinta paginas. El agente ubica la pagina del diagnostico, la convierte en imagen si esta escaneada y responde con el dato exacto.

Regla de oro: activa solo las que tu caso de uso realmente necesita.

4🔥

Elegir el modelo

El dropdown Model muestra varias opciones: Claude Sonnet 4.6, Claude Opus 4.6, Claude Sonnet 4.5, Claude Opus 4.5, GPT-5.5 y GPT-5-mini.

Para este taller, usa Claude Sonnet 4.6. Si mas adelante tu agente necesita mas capacidad de razonamiento, puedes cambiarlo despues sin perder el resto de la configuracion.

5🗃️

Conectar la Knowledge Base

Si ya creaste una Knowledge Base, aparece en un dropdown dentro del formulario del agente. La seleccionas y el agente queda conectado a esos documentos desde la primera pregunta.

6🌡️

Advanced options

Temperature y Top-P controlan que tan literal o creativo responde el modelo. Message limit y Token limit controlan cuanta conversacion anterior recuerda el agente.

Son opcionales. Los valores por defecto funcionan bien para un primer agente.

7💾

Guardar

Save & Close. El agente queda disponible para usarlo o para editarlo cuando quieras.

8📣

Publicar en el Agent Marketplace

Share AI Agent abre los permisos: decides si compartes el system prompt y los archivos del agente. Hay que marcar la casilla de confidencialidad antes de poder publicar.

Publish deja el agente visible en el Marketplace, con un link privado para invitar gente directamente.

9💬

Probarlo

Desde el chat, el selector de agente muestra tus agentes propios y los que otros compartieron contigo. Tambien puedes entrar por el Agent Marketplace y darle Start Chat directo desde la tarjeta.

/buenas practicas

Antes de servir el platillo

/1

Empieza simple. Activa solo Code Interpreter y Read File Toolkit al inicio. Agrega mas herramientas cuando el caso lo pida.

/2

Prueba y ajusta. El system prompt casi nunca queda perfecto a la primera.

/3

Revisa antes de publicar. Decide si el system prompt o los archivos deben ser publicos.

/4

Reutiliza. Guarda tus mejores system prompts como recetas para el proximo agente.
