# Agentes GenAI-Lab — capacitacion Allianz Colombia

Pagina de apoyo para la capacitacion sobre como armar agentes de IA en la
plataforma interna **Allianz GenAI-Lab**.

**Publicado en:** https://next-leap-s-a-s.github.io/agentes-genai-lab/

## Paginas

- **`index.html`** — Modulos 1-3 (Concepto, Por que agente, Ingredientes,
  Receta, Aplicacion). Ver detalle mas abajo.
- **`profundizacion-por-area.html`** — Modulo 4 y 5, profundizacion por
  area de negocio (Finanzas, Comercial, Operaciones, Indemnizaciones,
  Suscripciones, Marketing, Experiencia del cliente): casos reales con
  captura y fuente, radar de insurtechs, metodologia de diagnostico en 2h,
  caja de herramientas (Copilot/GenAI-Lab) y lienzo de proyecto imprimible.
  https://next-leap-s-a-s.github.io/agentes-genai-lab/profundizacion-por-area.html

## Que contiene `index.html`

- **Concepto** — que es un agente de IA, explicado con el mismo marco
  Rol · Contexto · Instruccion del taller de prompts.
- **Por que agente** — de que sirve un agente frente a repetir el mismo
  prompt, con un test interactivo de 6 preguntas para decidir cual conviene.
- **Ingredientes** — los 7 elementos de un agente en GenAI-Lab (nombre y
  descripcion, system prompt, modelo, knowledge base, agent files,
  herramientas, advanced options).
- **Receta** — checklist antes de entrar a la plataforma, mas 5 ejemplos de
  system prompt (ventas, cartera, siniestros, certificados, atencion al
  cliente) listos para copiar y adaptar.
- **Aplicacion** — los 9 pasos dentro de GenAI-Lab, con el desglose completo
  de las 8 herramientas disponibles (Web Search, Code Interpreter, Image
  Generation, Build PowerPoint, SharePoint/Confluence/Jira MCP, Read File
  Toolkit).

## Como esta construido

Un unico archivo `index.html` autocontenido: tipografias (Inter, IBM Plex
Mono), el logo de Next Leap y la foto del hero van incrustados en base64. No
hace ninguna peticion externa, asi que funciona sin conexion.

## Manejo de informacion

El contenido es material de capacitacion generico. No incluye datos reales
de clientes, polizas ni siniestros: los ejemplos usan marcadores genericos.
